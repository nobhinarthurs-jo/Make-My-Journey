# Make-My-Journey
A single-page bus and train ticket booking platform covering 80+ cities across India.

Key features

Bus and train booking: search by route and date, then filter and sort results by price, time, operator or class.
Interactive seat selection: sleeper berths, 2+2 seaters and train coach layouts with live availability.
Route visualisation: an embedded Google Maps view with stop-by-stop train timelines.
Smart checkout: passenger details, coupon codes, demo payment options and automatic fare calculation.
Digital e-ticket: a printable ticket with a QR code, PNR status check and cancellation with refund estimate.
Admin console: manage the bus and train fleet and view revenue and booking metrics.
Modern UI: a responsive dark neon theme with switchable colour modes.

Tech stack: HTML5, Tailwind CSS, JavaScript (ES6), Google Maps embed, Lucide icons, browser Local Storage

Note: This is a demo project. Schedules, fares and payments are sample data, and no real tickets are issued. It is not affiliated with redBus, AbhiBus, MakeMyTrip or IRCTC.
